# V1 — Running Tracker

## Goal

Create a simple running tracker for beginner runners without a backend or account.

## Features

- Add a running activity with date, distance, duration, and optional notes
- Calculate pace automatically
- Browse and delete running history
- Show total distance, total runs, average pace, and longest run
- Offer a simple rule-based next-run recommendation
- Persist activities and runner level in browser `localStorage`

## Limitations

- Data was available only in the browser and device where it was entered.
- There was no external database, AI, authentication, or Strava integration.

V2 kept the browser-based storage while adding Gemini recommendations. V3 migrates running activity persistence to Supabase.
